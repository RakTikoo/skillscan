# Expense Summariser

Reads a small CSV of expenses stored in its own folder and prints the
total spent in each category.

- Input: `expenses.csv` in this folder, one expense per line
  (`date,category,amount`).
- Output: one line per category with its total, printed in
  alphabetical order, plus a grand total.
- It only reads files inside its own folder.
- It does not change any files; it only prints the totals.
